# План проекта: ЭВЕРЕСТ HUB Web

## Цель
Создать удобный веб-сайт с личным кабинетом для агентов УЦ «Эверест».

## Основные функции
- Регистрация / Вход через email
- Подача заявок клиентов
- Сохранение заявок в Supabase
- Отправка заявок в Telegram @everestglav
- Раздел с шаблонами и скриптами
- Гайд по площадкам привлечения

## Технологический стек
- Next.js 15
- Supabase
- Vercel

## План реализации
1. Сгенерировать проект по промпту
2. Настроить Supabase
3. Настроить отправку в Telegram
4. Запустить на Vercel

Подробности в документации.
