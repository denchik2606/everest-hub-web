# ЭВЕРЕСТ HUB - Веб-сайт

Личный кабинет для агентов Учебного центра «Эверест»

## Что это

Обычный веб-сайт с личным кабинетом для агентов.

## Быстрый старт

1. Открой в **Cursor**
2. Скопируй промпт из `PROMPT_Everest_Hub_Web.md`
3. Сгенерируй проект
4. Настрой Supabase
5. Запусти на Vercel

- `PROMPT_Everest_Hub_Web.md` - Главный промпт для Cursor
- `EVEREST_HUB_WEB_PLAN.md` - Полный план проекта
