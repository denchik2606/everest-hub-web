# PROMPT: ЭВЕРЕСТ HUB - Обычный веб-сайт

Создай полноценный веб-сайт "ЭВЕРЕСТ HUB" - личный кабинет для агентов Учебного центра «Эверест».

## Технологии
- Next.js 15 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (Auth + PostgreSQL + Storage)
- sonner (уведомления)

## Основные требования

### Авторизация
- Email + password или Magic Link через Supabase
- Личный кабинет доступен только после входа

### Разделы

1. **Dashboard** - статистика, последние заявки, быстрые действия
2. **Новая заявка** - форма с ФИО, телефоном, свободным полем специальности, СНИЛС, фото, комментарий
3. **Мои заявки** - таблица заявок, фильтры, смена статуса
4. **Шаблоны и скрипты** - готовые тексты для Авито, Instagram, VK
5. **Площадки привлечения** - гайд по каналам
6. **Статистика** - графики и метрики

### Отправка в Telegram
При сохранении заявки должна происходить отправка сообщения в Telegram @everestglav через Bot API.

### Дизайн
- Тёмная тема
- Удобный мобильный интерфейс
- shadcn/ui стиль

Сделай чистую структуру проекта, готовую к развёртыванию на Vercel.
